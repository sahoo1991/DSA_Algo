# DSA_Algo

A comprehensive collection of Data Structures and Algorithms (DSA) solutions, algorithm implementations, coding patterns, and interview preparation resources using Python. Covers concepts from basic to advanced with clean, well-documented code.

## 📋 Project Structure

### Arrays
Core array manipulation problems and solutions (28 problems):
- **Basic Operations**: Linear search, largest element, second largest, maximum consecutive ones
- **Rotation & Rearrangement**: Left rotate by k, rearrange by sign, move zeroes to end
- **Searching & Sorting**: Union, intersection, 3sum, sort 0s 1s 2s, remove duplicates
- **Subarray Problems**: Max subarray sum (Kadane's), maximum product subarray, reverse pairs
- **Matrix Operations**: Spiral order, rotate 90 degrees, Pascal's triangle
- **Advanced Problems**: Count inversion, majority element, majority element II, leaders in array, next permutation

### Sorting
Fundamental sorting algorithms with implementations:
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

### Hashing
Hash-based problem solving techniques:
- Count subarrays with given sum
- Count subarrays with given XOR
- Longest subarray with given sum
- Largest consecutive sequence

## 🚀 Getting Started

### Prerequisites
- Python 3.7+

### Installation
1. Clone the repository:
```bash
git clone https://github.com/sahoo1991/DSA_Algo.git
cd DSA_Algo
```

2. No external dependencies required - all solutions use Python standard library

## 💡 How to Use

Each problem is organized in its respective folder with a standalone Python file. You can run any solution directly:

```bash
python Arrays/two_sum.py
python Sorting/merge_sort.py
python Hashing/count_subarrays_with_given_sum.py
```
